## Keyboard navigation

| Key                   | Action                       |
| --------------------- | ---------------------------- |
| Configurable shortcut | Open/close the palette       |
| `ArrowDown`           | Highlight next result        |
| `ArrowUp`             | Highlight previous result    |
| `Enter`               | Execute highlighted command  |
| `Escape`              | Always dismisses the palette |
